KittehCoin2.0 Core
==================

Setup
-----

[KittehCoin2.0 Core](https://www.kittehcoin.ca/) is the full-node wallet and network client for **KittehCoin 2.0 (MEOWS)**.
It downloads and stores the blockchain so you can send and receive MEOWS securely.

Website: https://www.kittehcoin.ca/  
Source: https://github.com/kittehcoin/KittehCoin2.0

Running
-------

### Unix

Unpack or build, then run `kittehcoin-qt` (GUI) or `kittehcoind` (daemon).

### Windows

Use the Windows installer from [Releases](https://github.com/kittehcoin/KittehCoin2.0/releases), or run `kittehcoin-qt.exe` from a packaged build.

### macOS

Drag KittehCoin2.0 Core to Applications, then open it.
