This is the official **KittehCoin 2.0 (MEOWS)** relaunch — a fresh chain, not a
continuation of the 2013 ledger. It is based on Litecoin Core v0.21.5.6 with
KittehCoin branding, economics, and consensus identity restored.

  <https://github.com/kittehcoin/KittehCoin2.0/issues>

Notable changes
===============

- Product name: **KittehCoin2.0 Core** · version **2.0.0** · ticker **MEOWS**
- Website / seeds: **kittehcoin.ca** (`seed1` / `seed2`)
- Network magic `MEOW` (`4D 45 4F 57`), P2P `22566`, RPC `22565`
- Address prefix **K**, bech32 HRP **meows**
- Scrypt PoW, 60s blocks, Kimoto Gravity Well (min 4 / max 1008)

- Genesis cold treasury (not burned) — see project docs / website
- Security remediations vs upstream baseline (supply tracking, KGW, genesis UTXO, etc.)
