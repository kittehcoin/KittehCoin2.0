KittehCoin2.0 Core
=================

Intro
-----
KittehCoin 2.0 (MEOWS) is a free open source peer-to-peer cryptocurrency.
Users hold the keys to their own funds and transact on a Scrypt Proof-of-Work
network without a central server.


Setup
-----
Run the Windows installer (KittehCoin2.0-Core-*-win64-setup.exe), or unpack
the portable Wallet folder and run kittehcoin-qt.exe.

KittehCoin2.0 Core is the full node wallet. It downloads and stores the
blockchain; first sync can take a while depending on your PC and network.
