# Security Policy

## Reporting a Vulnerability

To report security issues related to **KittehCoin2.0 Core**, email **contact@kittehcoin.ca** (not for general support).

You may also open a confidential report via GitHub Security Advisories on:
https://github.com/kittehcoin/KittehCoin2.0

Please do **not** file public GitHub issues for undisclosed vulnerabilities.
